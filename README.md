📸 Instagram Clone

Instagram Clone is a Kotlin-based Android social media application inspired by Instagram. The app demonstrates user authentication, account management, profile picture uploads, post and reels creation, and content management. Built with Jetpack Compose and Hilt Dependency Injection, it follows modern Android development practices with a scalable architecture and clean UI/UX.

✨ Key Features

* 🔐 User authentication
* 📝 Create and manage user accounts
* 👤 Profile management
* 🖼️ Upload profile pictures
* 📸 Create and manage posts
* 🎬 Create and manage reels
* 🗂️ Manage user-generated content
* ✏️ Update account information
* 🗑️ Manage created content
* 💉 Hilt Dependency Injection
* 🎨 Modern Jetpack Compose UI
* 📱 Responsive Android interface
* 🧩 Scalable application architecture
* ⚡ Modern Android development practices

🏗️ Architecture & Workflow

The application follows a structured and scalable Android architecture that separates UI components, application logic, data handling, and dependency management. Jetpack Compose is used to build the modern declarative UI, while Hilt provides dependency injection throughout the application.

Users can authenticate, manage their accounts and profiles, upload profile pictures, and create or manage posts and reels through an Instagram-inspired workflow. The architecture keeps features organized and makes the application easier to maintain and extend.

🛠️ Tech Stack

Kotlin • Android • Jetpack Compose • Hilt • Dependency Injection • Modern Android Architecture • UI/UX
